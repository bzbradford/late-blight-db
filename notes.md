# initial prompt

I want to create a website for reporting and displaying county-level late blight and cucurbit downy mildew disease detections. These are damaging but relatively rare diseases in commercial vegetable production, so knowing where outbreaks occur helps growers and extension agents focus their prevention efforts. The site should primarily feature a map of the US with states and county shapes, with a sidebar showing a detection feed, whereby clicking on a county with a detection highlights any incidents in the feed, and vice versa. Disease incidents will have some attributes like state/county, date, detection context (crop, farm operation), strain type if determined, and comments. Map symbology should initially just be color-coded based on recency of detection. A tab or toggle at the top should allow switching between diseases. Another menu should allow selecting the year. The site will need to have admin accounts that can create and edit disease incidents. For architecture I'm thinking Svelte 5/Sveltekit, shadcn-svelte, MapLibre, tailwind 4, postgres. Can you create a work plan for developing this app that can be followed by an orchestrator and sub-agents? What system pre-requisites will I need to have in place to avoid any roadblocks? What decisions need to be cleared up early on?
